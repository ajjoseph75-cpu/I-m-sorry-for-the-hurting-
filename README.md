# I'm Sorry 

## Files

- index.html
- style.css
- script.js

## Publish

1. Create or open a public GitHub repository.
2. Upload all three files to the root.
3. Commit your changes.
4. Open Settings → Pages.
5. Choose Deploy from a branch.
6. Select main and / (root).
7. Save.

The site contains no images or external dependencies.
